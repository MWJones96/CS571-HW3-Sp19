# CS571 Homework 3: Snowboard Central

A static single-page layout ("Snowboard Central") built with plain HTML and CSS.

## Overview

Coursework for USC CSCI 571, Web Technologies, Spring 2019. The assignment was to reproduce a given page design using HTML and CSS only. There is no JavaScript and no build step.

## What's implemented

- A fixed-width (750 px) hero banner with a full-cover background photograph, an inline navigation list (Home, About, Gallery, Journal, Contact), a heading, an introductory paragraph and a "Learn More" button.
- A two-by-two photo grid laid out with a table.
- A description paragraph with a photography credit, and a footer banner.
- Raleway typography loaded from Google Fonts, with Arial as a fallback.

## Tech stack

- HTML
- CSS (Google Fonts for the Raleway typeface)

## Getting started

No installation is needed. Open `fgdsradcrdfg.html` in a web browser. An internet connection is required, because the font and all images are loaded from remote URLs.

## Project structure

```
fgdsradcrdfg.html   Page markup
gdhfsfrtgrsf.css    Page styles
```

## Status and limitations

- All images are hot-linked from `http://csci571.com/hw/hw3/images/`, the course website. If those URLs are no longer served, the page will render without its photographs.
- The body copy is placeholder (lorem ipsum) text supplied with the assignment.
